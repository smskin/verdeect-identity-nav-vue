# Чек-лист встраивания и запреты

Страница для ревью и для агента: короткие проверяемые условия. Подробности —
по ссылкам.

## Обязанности продукта

- [ ] Смонтированы **два** вида навигации: `CrossServiceRail` перед шапкой
      и **один** мобильный — `CrossServiceMenu` первым блоком выдвижного меню
      **либо** `CrossServiceBar` плашкой внизу
- [ ] Мобильный вид выбран **один**, а не оба: они взаимоисключающие, и вместе
      покажут одни и те же пункты дважды
- [ ] `currentUrl` передан явно в оба и **абсолютный**
- [ ] `profileUrl` передан — иначе шестерёнка настроек не появится
      даже у вошедшего
- [ ] `locale` заполнен для **гостя**: язык вошедшего приходит в профиле,
      а язык гостя знает только продукт — без него гостевой рейл выйдет
      русским на англоязычной установке
- [ ] Класс резервирования места ставится по **непустому составу пунктов**,
      а не по факту входа
- [ ] Правила переключения представлений написаны со **своим** порогом — тем же,
      что у навигации продукта
- [ ] Эти правила стоят **вне `@layer`**
- [ ] Оболочка сдвинута вправо на `--cross-service-rail-width` — шапка,
      навигация и содержимое
- [ ] Origin установки включён в `img-src` политики содержимого — ради логотипа
- [ ] Origin хранилища иконок включён в `img-src` — ради иконок пунктов; он виден
      в ссылках `iconUrl` и в продукт не зашивается
- [ ] Срок кэша данных рейла заметно меньше срока подписи ссылок, который задаёт
      установка
- [ ] `--highlight-background` и `--highlight-color` объявлены либо приняты
      запасные

**Не обязанность продукта, но условие работы иконок:** хранилище иконок
установки обязано отдавать `Access-Control-Allow-Origin`. Иконка рисуется
маской, а маску браузер загружает запросом CORS — без разрешения она
не применяется. Настраивается это на стороне установки, у продукта средств
нет; признак — заглушки первой буквой вместо иконок у всех пунктов сразу.

## Запреты

| Нельзя | Почему |
| --- | --- |
| Копировать каталог компонентов или файл стилей в продукт | Эталон один; копия разойдётся на первой правке |
| Править компоненты у себя «на время» | Переносят не всегда — так уже расходились в трёх местах |
| Заводить пороги ширины в пакете | Порог принадлежит навигации продукта |
| Ставить правила переключения внутри `@layer` | Неслоистая оболочка перебьёт их, и оба представления будут видны |
| Опускать `currentUrl`, полагаясь на умолчание | Сохраняемый макет не перемонтируется — подсветка застрянет |
| Передавать `currentUrl` относительным путём | Правило сравнивает схему и хост; путь без них не подсветит ничего |
| Применять свои правила видимости к пунктам | Они приходят отфильтрованными по роли |
| Ожидать, что `UserMenu` сам выполнит выход | Он лишь издаёт событие `logout` |
| Складывать пункты рейла в браузерное хранилище | Кэш ведёт бэкенд продукта |
| Собирать формы имени в интерфейсе | Их считает бэкенд и отдаёт готовыми |
| Опираться на классы оболочки продукта в стилях рейла | Рейл не зависит от состояния чужой навигации |

## Признаки исправного встраивания

- На широком экране видна полоса слева, на узком — тот же состав первым блоком
  выдвижного меню; **одновременно они не видны никогда**.
- Текущий раздел подсвечен, и подсветка **меняется при переходах** без
  перезагрузки страницы.
- При пустом составе пунктов рейла нет вовсе, включая логотип, и оболочка
  не оставляет под него пустую полосу.
- Логотип установки отрисован, а не заменён рамкой битого изображения.
- Иконки пунктов видны глифами, а не квадратами.
- Выход из блока пользователя выполняет тот путь выхода, который принят
  в продукте.

## Если что-то не так

| Симптом | Обычная причина |
| --- | --- |
| Видны оба представления сразу | Правила переключения попали внутрь `@layer` |
| Подсветка застряла на первой странице | `currentUrl` не передан либо передан один раз |
| Не подсвечено ничего | `currentUrl` относительный, без схемы и хоста |
| Логотип не грузится | Origin установки не включён в `img-src` |
| Вместо иконок первые буквы имён | Origin хранилища не включён в `img-src`; либо хранилище установки не отдаёт `Access-Control-Allow-Origin`; либо кэш продукта пережил подпись ссылок; либо установка ещё не перешла на загружаемые иконки (последнее штатно) |
| Иконки пропадают время от времени, в консоли ошибка CORS | Версия пакета ниже 0.4.1: зонд грузился без `crossorigin` и клал в общий кэш ответ без разрешения CORS, отчего маска переставала применяться, а узел исчезал целиком. Лечится обновлением пакета |
| Навигация продукта наезжает на рейл | Оболочка не сдвинута на ширину рейла |
| Подписи по-английски у русского пользователя | `locale` продукта перекрыл профиль — проверьте, что профиль приходит |
| Гостевой рейл по-русски на англоязычной установке | продукт не заполнил `locale` в свойствах identity |
| Шестерёнки настроек нет у вошедшего | `profileUrl` не передан в вид навигации либо пришёл пустым |
| Одни и те же пункты видны дважды на телефоне | смонтированы оба мобильных вида — оставьте один |
| Подписи пунктов пропали в полосе | так и задумано: в полосе имя показывает подсказка при наведении |

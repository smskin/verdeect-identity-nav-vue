# AGENTS.md

> Структурная карта репозитория для агентов и новых разработчиков. Поддерживать
> в актуальном состоянии при значимых изменениях раскладки; подробности не
> дублировать — на них ссылаться.

## О проекте

npm-библиотека Vue-компонентов кросс-сервисной навигации Verdeect Identity:
рейл переходов между сервисами, блок пользователя единого входа, их визуальный
слой, вывод состояния рейла из свойств бэкенда и вход в продукт для браузерных
прогонов. Поставляется **исходниками, без шага сборки**.

Подробно — [.ai-factory/DESCRIPTION.md](.ai-factory/DESCRIPTION.md).

## Стек

- **Язык:** TypeScript 5, режим `strict`
- **Библиотека представления:** Vue 3.5, SFC `<script setup lang="ts">`
- **Оформление:** обычный CSS с переменными темы продукта
- **Прогонщик:** `@playwright/test` в роли прогонщика Node
- **Сборка:** отсутствует намеренно — интерфейс собирает Vite потребителя
- **База данных и ORM:** отсутствуют — данные приходят только props

## Структура

```
.
├── src/
│   ├── cross-service/      эталон экосистемы: компоненты рейла и блока
│   │                       пользователя, их типы, словарь подписей,
│   │                       правило текущего пункта. Правится по существу
│   ├── identity/           ядро вывода состояния рейла; зависимость — vue
│   ├── inertia/            адаптер над usePage(); единственное место
│   │                       с импортом @inertiajs/vue3
│   ├── playwright/         loginAs/logout/credentialsFor для прогонов
│   │                       продуктов установки
│   └── style.css           визуальный слой, вход ./style.css
├── scripts/                проверки: полнота словаря, изоляция каталога
├── tests/                  правило подсветки текущего пункта (16 наборов)
├── docs/                   документация для встраивающих продуктов
└── .ai-factory/            контекст агента: описание, архитектура, правила
```

## Ключевые точки входа

| Файл | Назначение |
| --- | --- |
| `package.json` | пять входов в `exports`, необязательные одноранговые зависимости, состав `npm test` |
| `src/cross-service/index.ts` | вход `.` — компоненты и типы; правила каталога в докблоке |
| `src/identity/index.ts` | вход `./identity` — `useIdentityView` и типы контракта с бэкендом |
| `src/inertia/index.ts` | вход `./inertia` — адаптер `useIdentity` |
| `src/playwright/index.ts` | вход `./playwright` — вход в продукт для сценариев |
| `src/style.css` | вход `./style.css` — оформление рейла и блока пользователя |
| `scripts/check-component-isolation.mjs` | девять условий изоляции; закреплённые перечни `document` и консоли |
| `scripts/check-component-strings.mjs` | три условия полноты словаря подписей |
| `playwright.config.ts` | прогонщик Node; браузер не поднимается |
| `tsconfig.json` | `strict`, `noEmit`, типы `node` и `vite/client` |

## Правила для агентов

- **Команды оболочки выполняются по одной.** Не объединять через `&&`, `||`
  или `;` — каждая команда проверяется правилами разрешений отдельно.
  - Неверно: `git checkout main && git pull`
  - Верно: сначала `git checkout main`, затем `git pull origin main`
- **Правка `src/cross-service` — только по существу.** Каталог сверяется
  с эталоном глазами; косметика создаёт шум, который разбирают вручную.
- **Сборщик, бандлер, Tailwind, storybook и отдельный прогонщик тестов
  в этот репозиторий не заводятся** — см. `.ai-factory/DESCRIPTION.md`.
- **Перед сдачей работы прогонять `npm test` целиком:** четыре проверки идут
  подряд, падение первой скрывает остальные.
